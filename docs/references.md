# 공개 프로젝트 조사와 구현 범위

확인일: 2026-09-13

## 참고 프로젝트

- [DOOMFLY](https://github.com/nftechie/doomfly): MaleCNS 연결망에 게임 화면을 입력하고 신경 활동을 조작으로 변환하는 실험입니다. 코드 라이선스는 MIT입니다. README는 현재 학습 성공을 입증하지 못했다고 명시합니다. 감각, 신경 계산, 운동 출력을 분리하는 구조와 실패 결과도 기록하는 방식을 참고했습니다.
- [Fly64](https://github.com/ornata/fly): Mario의 시점에서 감각 입력을 얻는 게임 연결 사례입니다. macOS 중심의 실험이고 ROM이 별도로 필요합니다. 조사한 루트 목록에서는 라이선스 파일을 확인하지 못했으므로 코드를 복사하지 않았습니다.
- [FlyGym / NeuroMechFly](https://github.com/NeLy-EPFL/flygym): 감각과 몸, 환경의 상호작용을 구성하는 연구용 프레임워크입니다. Apache-2.0입니다. 전체 뇌 시뮬레이터 그 자체로 취급하지 않습니다.
- [FlyBrain](https://github.com/snedea/flybrain): 브라우저 Web Worker의 연결망 계산과 시각화 사례입니다. MIT 코드이며 실제 FlyWire 유래 데이터에는 별도 조건이 적용됩니다. `js/connectome.js`, `js/fly-logic.js`에는 수작업 그룹과 행동 규칙도 있어 전체 행동이 연결망에서만 나온다는 설명은 그대로 받아들이지 않았습니다.

외부 코드와 데이터는 앱에 복사하거나 포함하지 않았습니다. 위 프로젝트의 구조를 참고해 미로 실험을 독립 구현했습니다.

## 현재 구현

- 시드가 있는 랜덤 미로: 모든 칸이 연결되며 일부 순환 통로를 추가합니다.
- 냄새는 먹이에서 열린 통로로 퍼지는 단순 확산장입니다. 유체 시뮬레이션은 아닙니다.
- 게임용 제어기는 주변 네 방향의 통로, 냄새, 방문 횟수와 현재 방향만 받습니다. 전체 미로나 출구 좌표, 최단 경로는 받지 않습니다.
- 방문 횟수는 게임용 기억입니다. 초파리의 생물학적 공간 기억을 구현한 것이 아닙니다.
- 방향 점수에 반응 가중치와 이전 활성도, 시드 난수를 적용합니다. 실제 뉴런 모델이나 실제 연결망 데이터는 아직 사용하지 않습니다.
- 가중치는 즉시 반영됩니다. 동일 경로 재현은 처음부터 같은 가중치를 유지할 때 보장됩니다. 기록 표는 최종 가중치이며 중간 편집 이력을 재생하지 않습니다.
- 일시 정지는 상태를 보존합니다. 재도전은 제어기와 난수를 초기화합니다. 같은 시드·크기의 최근 완료 경로를 겹쳐 보여줍니다.

## 실제 연결망 연동에 필요한 작업

`Controller`는 교체 가능한 감각/운동 경계입니다. 실제 데이터 입력 뉴런과 출력 뉴런의 ID 및 선정 근거, 신호 변환과 동역학, 데이터 버전과 해시를 먼저 고정해야 합니다. 계산 비용에 따라 Web Worker 또는 로컬 Python 서비스에 모델을 배치할 수 있습니다. 현재 이 어댑터나 데이터 다운로드는 구현하지 않았습니다.

FlyWire 데이터는 [공식 안내](https://edit.flywire.ai/principles.html)에 따르면 CC BY-NC 4.0입니다. DOOMFLY/Fly64가 사용하는 MaleCNS는 별도 데이터셋이므로 같은 라이선스라고 가정하면 안 됩니다. 실제 채택 시 [원 배포처](https://male-cns.janelia.org/download/)의 해당 파일 조건을 확인해야 합니다.
