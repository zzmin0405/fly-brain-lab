# 전체 초파리 뇌 게임화 설계

## 목표

게임 속 초파리가 미로의 전역 지도를 보지 않고, 연결망 계산 결과로 이동하도록 만든다. 플레이어는 뉴런 그룹 또는 시냅스 계수의 배율을 바꾸고, 여러 랜덤 미로에서 일반화 성능을 비교한다.

## 실행 구조

```text
Canvas 게임 클라이언트
  └─ WebSocket / JSONL
      └─ 로컬 brain-runner (Python + NumPy/Numba 또는 C++)
          ├─ FlyWire/MaleCNS 원본 어댑터
          ├─ LIF 상태와 CSR 연결망
          ├─ 감각 입력 매핑 (시각·후각·접촉)
          └─ 운동 출력 매핑 (전진·회전·정지)
```

전체 연결망은 브라우저 번들에 넣지 않는다. 원본 파일, 데이터 버전, SHA-256, 라이선스를 별도 manifest에 기록하고 첫 실행 때 로컬 경로를 지정하게 한다. 서버에 업로드하거나 자동 다운로드하는 흐름은 나중에 별도로 승인한다.

## 한 틱의 계약

클라이언트가 보내는 입력은 초파리의 위치에서 측정한 감각값뿐이다.

```json
{
  "tick": 42,
  "vision": [0.1, 0.4, 0.0, 0.8],
  "odor": [0.2, 0.3, 0.1, 0.0],
  "contact": [0, 1, 0, 0],
  "reward": 0
}
```

시뮬레이터는 운동 출력과 선택적 관찰용 뉴런 활동을 반환한다.

```json
{
  "tick": 42,
  "motor": { "forward": 0.72, "turn": -0.18 },
  "spikes": { "DNp20_L": 0.31, "DNp20_R": 0.22 }
}
```

목표 좌표, 최단 경로, 미로 전체 배열은 이 계약에 포함하지 않는다. `reward`도 먹이 도착·충돌처럼 환경에서 발생한 사건만 전달한다.

## 단계별 구현

1. 현재 `Controller`를 WebSocket 클라이언트로 교체하고, 로컬 데모 컨트롤러를 fallback으로 유지한다.
2. 공개 데이터셋에서 감각 뉴런과 운동 뉴런 ID를 고정하고, 선정 근거와 인용을 manifest에 기록한다.
3. 먼저 1천~1만 뉴런 부분 회로를 LIF로 검증한다. 미로 성공률, 충돌률, 틱 지연을 고정 seed로 회귀 테스트한다.
4. 검증된 인터페이스에 전체 연결망을 연결한다. 전체 모델은 수 GB 메모리와 네이티브 계산이 필요할 수 있으므로 브라우저가 아니라 로컬 runner에서 실행한다.
5. 가중치 편집은 원본을 덮어쓰지 않고 배율 patch로 저장한다. 실행마다 데이터 버전·patch·미로 seed·결과를 함께 기록한다.

## 게임 설계 원칙

- 성공만 보상하지 않고 탐색률, 충돌, 에너지, 반복 방문을 함께 점수화한다.
- 한 미로에 과적합되지 않도록 평가 미로와 숨겨진 검증 미로의 seed를 분리한다.
- 연결망에서 자연스럽게 나온 결과와 사람이 만든 입력·출력 매핑을 UI와 문서에서 구분한다.
- “실제 초파리 뇌”라는 표현은 사용한 데이터셋과 모델 범위를 함께 표시할 수 있을 때만 사용한다.
