# Fly Brain Lab

가중치를 조정해 초파리의 행동을 바꾸고 자동 플레이를 관찰하는 웹 게임 프로토타입입니다.

## 실행

Node.js 22.17 이상(22 계열)과 npm을 사용합니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다.

## 개발 명령

- `npm run dev`: 개발 서버
- `npm run check`: 타입 검사, 린트, 프로덕션 빌드
- `npm run format`: 코드 포맷 정리
- `npm run preview`: 빌드 결과 미리보기

## 구성과 현재 범위

React, TypeScript, Vite, Canvas 2D를 사용합니다. 먹이 추적, 탐색, 위험 회피 가중치를 변경하면 이동에 즉시 반영됩니다. 정지 후 다시 시작하면 출발점부터 새로 실행합니다.

현재는 동작을 검토하기 위한 간단한 게임용 행동 모델이며 실제 초파리 뉴런이나 연결망을 재현하지 않습니다. 서버, 계정, 외부 API 키 없이 실행됩니다.
